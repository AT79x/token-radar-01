A token launch radar for make.fun's token-radar-01 bounty by @calm-fox-41 (GitHub at79x): it reads a sealed snapshot of every protocol DefiLlama tracks, ranks the protocols that record no token by what their launch would be worth, and shows the steps to farm each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
